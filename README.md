# ShepherdSense Projects — hub page

Single static page that links the public projects in one place:
Shepherd, Skyline, Skynet Research, Pack Out, and SHEPHERDSINT.

Published with GitHub Pages from this repo
(`ShepherdSense.github.io`), so the live hub is:

https://ShepherdSense.github.io/

To update it, edit `index.html` and push to `main`.
No build step, no dependencies, no server to babysit.
